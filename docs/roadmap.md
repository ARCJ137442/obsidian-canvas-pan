# 开发路线图

> 2026-08-26 基线：桌面、Android 手机和平板均已通过“首次编辑前／编辑中／点击空白退出编辑后”的实体键盘验证；本轮指针租约修复可发布。以下项目不得取代已验证的安全边界。

## P0：维护诊断与行为的一致性

- 为事件处理结果显式区分“按键匹配”“实际执行”“应当消费”，避免未来出现识别了方向却无动作仍阻断宿主的回归。
- 给指针租约增加更完整的生命周期集成测试：Canvas 关闭、窗口替换、标签切换、Modal 打开和 Document 更换。
- 将诊断中的重复守卫或效果记录聚合成摘要，在保持首条、末条和计数的前提下降低手机报告噪声。

## P1：降低编辑路径开销

- 保持诊断关闭时只有轻量布尔判断，不做能力遍历、视口快照或字符串序列化。
- 复核正常 10 ms 平移循环中的分配；只在真实性能证据出现时优化，不提前改变速度曲线。
- 为诊断开启／停止、Window error 监听和 interval 异常停止补泄漏与重复注册测试。

## P2：Obsidian Canvas 内部 API 兼容

- 在 Obsidian 大版本升级后只读比较桌面与移动端的 Canvas 能力快照。
- 只有出现“上下文已解析、动作已接受、视口仍不变”的真机证据时，才评估 `panBy`、`setViewport` 或新的内部字段。
- 任何新视口策略必须保留当前 legacy 路径作为受控回退，并验证位置、目标位置、缩放与重绘状态的一致性。

## 暂不推进

- 不新增常驻遥测、后台轮询或自动上传。
- 不用 `activeLeaf`、唯一 Canvas、文件名或当前标签猜测键盘事件归属。
- 不用自动切换标签掩盖 Android 焦点问题。
- 不因某次平台差异删除输入、编辑、composition、Modal 或多窗口闸门。
